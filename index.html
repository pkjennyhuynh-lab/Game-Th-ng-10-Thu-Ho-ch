⚠️ Lỗi dữ liệu trò chơi

Không thể đọc cấu hình từ file questions.json.

Hướng dẫn khắc phục:
  • Kiểm tra tính chính xác của file questions.json.
  • Đảm bảo các màn (stages) tham chiếu đúng mã cặp thẻ (pairIds) hoặc mã câu hỏi (questionIds).
  • Chạy game qua HTTP server (ví dụ: python -m http.server 8000).
